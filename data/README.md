# Данные

## raw/

- **`MAST_371_2025111002_Raw_Recode.csv`** (46 КБ) — основной источник анализа:
  острая лабораторная стресс-проба MAST, 371 испытуемый.
  Колонки: демография (`SubID`, `Age`, `BMI`, `Gender`), группа (`Stress`/`Control`),
  эксперимент (`Exp`), кортизол (`Cortisol_01..05`, `LogCortisol_01..05`),
  психометрика (`Trait_Anxiety`, `State_anxiety_02..05`, `Positive_02..05`,
  `Negative_02..05`).
  Ссылка на источник и условия использования — уточняются у держателя набора
  (MAST, Multimodal Acute Stress Test).

  > ВАЖНО: идентификатор испытуемого — колонка **`SubID`** (371 уникальных
  > значений). Колонка `Subject` повторяется между экспериментами (FLH01/FLH02)
  > и относится к **разным людям**, поэтому как группировка она не используется.

- `MAST_371_2025111002_Raw.csv` (2 МБ) и `MMASH.zip` (25 МБ) — полный сырой
  дамп / сырые данные MMASH. Не загружены в репозиторий (см. `.gitignore`).

## processed/

Производные датасеты, генерируются `python scripts/run_data.py`:

- `mast_wide.csv` — 371 × 43: производные признаки (пик кортизола, AUCg/AUCi,
  наклоны, пики аффекта и т.д.).
- `mast_long_cortisol.csv` — 1855 × 11 (5 сэмплов × 371 испытуемый) для
  байесовской иерархической модели.
- `mast_long_psych.csv` — 1484 × 12 (4 точки × 371) психометрики.
- `mast_17d.csv` / `mast_cortisol_5d.csv` — наборы переменных для TDA
  (17 физиологических переменных / 5 кортизоловых).
- `MMASH_long.csv` — производный длинный датасет MMASH (5 переменных +
  `Daily_stress`), используется только регрессионным тестом переносимости
  метрик (`scripts/run_repro_mmash.py`). Сырые данные MMASH распространяются
  по лицензии CC-BY (DataPaper MMASH, https://physionet.org/content/mmash/).
